# 02: Product pages with related items get stock and price alerts

**What to build:** A shop page that shows the product plus related items counts as a product page. Stock and price alerts read only the product.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] The product is the one item whose canonical URL is the page's. With none, a page with exactly one item is that item's page.
- [x] The product check, the product title and the price currency all use that item.
- [x] URL monitors on product pages keep their match alerts.
