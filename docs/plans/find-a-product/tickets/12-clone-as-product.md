# 12: Clone a monitor as a product

**What to build:** The Clone action on a monitor card already opens the create sheet with the monitor's name, URL and prompt filled in. It now also fills the "Find a product" tab: the monitor's name as the search, and the alert criteria guessed from its prompt. A user can turn an old URL monitor into a product in a few clicks. The original monitor is left alone.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] Clone still fills the "Paste a URL" tab exactly as today.
- [ ] When the beta is on, Clone also fills the "Find a product" tab with the monitor's name as the search term.
- [ ] Criteria are guessed from the prompt, for example "in stock" means back in stock and "under £300" means below 30000 minor units. The user can change them.
- [ ] The sheet opens on the "Find a product" tab when the beta is on, and on "Paste a URL" otherwise.
- [ ] The original monitor is not changed or deleted.
